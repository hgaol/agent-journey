# Redact presentation without altering evidence

AgentJourney preserves Source Evidence and Canonical Activity exactly while recording high-confidence Sensitive Findings as separate evidence-linked spans. Journey presentation, evidence inspection, search snippets, and future exports mask those findings by default and require deliberate local action to reveal or export them unredacted. This maintains forensic integrity and useful local review while reducing accidental screen or export exposure, but it is explicitly not encryption and does not protect the unencrypted archive files.
