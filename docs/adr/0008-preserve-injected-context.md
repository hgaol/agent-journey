# Preserve injected context as Canonical Activity

Persisted system instructions, repository rules, environment context, and synthetic source-role messages become Context Injection rather than being omitted or mislabeled as Human Input. Source-Native Renderers may collapse activity that their native interfaces conceal, but forensic views can reveal it and uncertain origins remain unknown. This adds classification and UI complexity, but avoids presenting a cleaner and materially false explanation of agent behavior.
