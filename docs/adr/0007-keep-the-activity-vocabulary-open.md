# Keep the canonical activity vocabulary open

AgentJourney uses a small stable set of common Activity kinds while retaining namespaced source-specific meaning and representing unknown records as visible Unclassified Activities linked to Source Evidence. Capture succeeds when agents introduce new records, and later source interpretations may rebuild richer Canonical Activity from the preserved evidence. This requires neutral fallback UI and schema-extension discipline, but prevents format drift from causing rejection or silent data loss.
