# Sandbox Renderer Plugins

Third-party Renderer Plugins execute inside a capability-limited sandbox: their styles are confined to the Journey Stage, their code receives only an immutable rendering view, and filesystem, network, archive-wide data, browser storage, and Platform Shell access are denied by default. Source Evidence is never available to a renderer; only Canonical Activity, reviewed source-specific fields, safe Artifact handles, fidelity metadata, and renderer settings cross the rendering boundary. Other additional capabilities require explicit user grants. Bundled renderers may be internally optimized, but they are authored and tested against the same public contract. This limits some integrations and adds isolation overhead, but preserves Local Custody when rendering untrusted community code.
