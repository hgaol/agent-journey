# Start Replay from a fresh first-frame Stage

Switching from Review View to Replay View—or selecting a different streaming mode that enters Replay—atomically resets the Playhead to frame zero and starts playback whenever the selected Replay mode is autoplay-safe. The first frame remains visible for at least 400 ms before advancing. Wholly untimed event/recorded histories still enter paused and require manual stepping or explicitly selected Simulated Streaming.

The Journey Stage iframe is recreated when its presentation view changes between Review and Replay. This prevents a delayed message-channel render from leaving the complete Review transcript visible during the first Replay transition. Stream-mode reset effects skip their initial mount so they cannot cancel a fast first interaction, and a previous executable renderer tree is withheld while its Replay projection is loading. This adds one iframe reload at each view transition but guarantees that progressive presentation never starts from stale full-transcript DOM.
