# Simulate prompt typing before visual submission

Replay may optionally present evidenced final Human Input as a simulated draft in the source-native composer. Deterministic character frames reveal the draft with a perceptible minimum cadence even at high speed, a short submission hold moves the complete prompt into the transcript, and only then do subsequent Activities appear. The option is enabled by default in Replay and MP4 export, can be changed to instant prompt submission, uses a dedicated 0.5×–4× Typing Speed independent from response Streaming Speed and Timeline Speed, and is visibly labeled in browser Replay and MP4 metadata.

Human Input over 1,000 characters is treated as likely pasted content for presentation: after a brief empty-composer frame, AgentJourney inserts the complete input in one Simulated Prompt Paste frame and then submits it. Typing Speed does not alter this paste transition. The UI labels Journeys containing this behavior as `large inputs pasted`; it does not claim that Source Evidence recorded a clipboard action. This prevents pasted logs and documents from becoming tens of thousands of invented keystrokes while preserving every character in the submitted Human Input.

Typing cadence is deadline-based rather than render-cycle-based: if a large transcript takes longer to paint, Replay catches up to the scheduled character position instead of adding rendering latency to every character. After the first draft frame, the iframe receives draft-only updates and does not rebuild or retransmit the transcript for each keystroke. Therefore one Typing Speed has the same characters-per-second target across Journey sizes. Paste insertion is a separately labeled presentation transition, not accelerated typing.

This is presentation only. Source Evidence establishes the final prompt and usually its submission timestamp, not keystrokes, editing history, or typing cadence. AgentJourney therefore never promotes draft frames to Canonical Activity, never claims input timing was recorded, and never sends the prompt to a Source Agent. Existing event/Recorded Streaming fidelity remains unchanged; wholly untimed histories still require explicitly selected Simulated Streaming before autoplay or MP4 export.
