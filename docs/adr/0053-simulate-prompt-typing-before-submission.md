# Simulate prompt typing before visual submission

Replay may optionally present evidenced final Human Input as a simulated draft in the source-native composer. Deterministic character frames reveal the draft with a perceptible minimum cadence even at high speed, a short submission hold moves the complete prompt into the transcript, and only then do subsequent Activities appear. The option is enabled by default in Replay and MP4 export, can be changed to instant prompt submission, uses a dedicated 0.5×–4× Typing Speed independent from response Streaming Speed and Timeline Speed, and is visibly labeled `SIMULATED prompt typing` in browser Replay and MP4 metadata.

This is presentation only. Source Evidence establishes the final prompt and usually its submission timestamp, not keystrokes, editing history, or typing cadence. AgentJourney therefore never promotes draft frames to Canonical Activity, never claims input timing was recorded, and never sends the prompt to a Source Agent. Existing event/Recorded Streaming fidelity remains unchanged; wholly untimed histories still require explicitly selected Simulated Streaming before autoplay or MP4 export.
