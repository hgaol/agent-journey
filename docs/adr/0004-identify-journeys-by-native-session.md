# Identify Journeys by source agent and native session

AgentJourney identifies a Journey by its Source Agent and Native Session Identity, while source paths are recorded only as Source Provenance and source-content fingerprints distinguish revisions. A missing native identity receives a clearly marked Synthetic Identity. This permits moved, copied, scanned, and manually imported files to converge on one Journey; conflicting evidence that claims the same identity is surfaced instead of silently merged.
