# Match each source agent's native TUI visual hierarchy

Source-Native Renderers should reproduce the source TUI's hierarchy, density, typography, prompts, tree markers, collapsed details, and terminal palette—not merely recolor generic canonical cards. Calibration uses both supplied screenshots and ANSI captured from installed agents. Claude Code uses its current three-line block mascot, compact gray `❯` prompts, white bullet-led output, muted tool branches, lavender inline code/path accents, gray editor rules, and colored model/workspace footer. GitHub Copilot CLI uses the observed cyan active tab with black Sessions/Gists tabs, black timestamped prompt bar, italic `Thinking…` rows, green intent/tool markers, yellow shell markers, magenta output markers, cyan underlined URLs, dark inline-code chips, native tool descriptions with line counts and long durations, workspace-above-editor placement, and keyed footer treatment. Pi uses its built-in dark ANSI palette, plain expanded italic thinking, green successful and red failed tool blocks, gold Markdown headings, teal list/path accents, evidenced tool durations, thinking-level-specific editor borders, terminal-row editor spacing with a cell-sized cursor and right-edge rule, and a two-line workspace/model footer. Codex uses its dim rounded startup card, `›` prompts, dim `•` activity markers, inline cyan terms, tool-result branches and separators, minimal composer, and colored model/workspace status line. Empty signed reasoning envelopes do not become semantic Reasoning Activities, and native presentation suppresses legacy empty-reasoning rows plus non-model lifecycle transitions rather than exposing selectable marker-only lines. Forensic details remain available in Source Evidence and the Activity inspector; native presentation may hide chrome but never deletes meaningful Canonical Activity or Source Evidence.
