# Match each source agent's native TUI visual hierarchy

Source-Native Renderers should reproduce the source TUI's hierarchy, density, typography, prompts, tree markers, collapsed details, and terminal palette—not merely recolor generic canonical cards. The Claude Code renderer therefore uses its charcoal terminal surface, pixel mascot, full-width `❯` prompt bars, plain bullet-led assistant output, concise tool branches, lavender inline code/path accents, colored terminal context metadata, and hidden canonical metadata/source-detail noise. The GitHub Copilot CLI renderer uses its cyan tab strip, black timestamped prompt bar, italic `Thinking…` rows, green intent/tool markers, yellow shell markers, magenta output markers, cyan underlined URLs, dark inline-code chips, and native editor/footer treatment. Forensic details remain available in the Activity inspector; native presentation may hide chrome but never deletes Canonical Activity or Source Evidence.
