# Match each source agent's native TUI visual hierarchy

Source-Native Renderers should reproduce the source TUI's hierarchy, density, typography, prompts, tree markers, collapsed details, and terminal palette—not merely recolor generic canonical cards. The Claude Code renderer therefore uses its charcoal terminal surface, pixel mascot, full-width `❯` prompt bars, plain bullet-led assistant output, concise tool branches, lavender inline code/path accents, colored terminal context metadata, and hidden canonical metadata/source-detail noise; forensic details remain available in the Activity inspector. Native presentation may hide chrome but never deletes Canonical Activity or Source Evidence.
