# Match each source agent's native TUI visual hierarchy

Source-Native Renderers should reproduce the source TUI's hierarchy, density, typography, prompts, tree markers, collapsed details, and terminal palette—not merely recolor generic canonical cards. The Claude Code renderer therefore uses its charcoal terminal surface, pixel mascot, full-width `❯` prompt bars, plain bullet-led assistant output, concise tool branches, lavender inline code/path accents, colored terminal context metadata, and hidden canonical metadata/source-detail noise. The GitHub Copilot CLI renderer is calibrated against the installed CLI's ANSI output as well as supplied screenshots. It uses the observed cyan active tab with black Sessions/Gists tabs, black timestamped prompt bar, italic `Thinking…` rows, green intent/tool markers, yellow shell markers, magenta output markers, cyan underlined URLs, dark inline-code chips, native tool descriptions with line counts and long durations, workspace-above-editor placement, and keyed footer treatment. The Pi renderer uses colors sampled from the supplied native screenshots, aligned with its built-in dark theme: charcoal terminal surface, gray prompt bars, expanded italic titled thinking, green successful and red failed tool blocks, gold Markdown headings, teal list/path accents, evidenced tool durations, and its bordered editor/footer. Shared charcoal, prompt, accent, muted-text, tool-marker, editor, and footer colors for Claude Code and GitHub Copilot CLI are likewise sampled from their supplied references rather than approximated by a generic palette. Forensic details remain available in the Activity inspector; native presentation may hide chrome but never deletes Canonical Activity or Source Evidence.
