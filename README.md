# AgentJourney GitHub Pages

Static landing site for <https://hgaol.github.io/agentjourney/>.

`demo/index.html` is generated from synthetic Canonical Activity by AgentJourney's real `renderPresentationHtml()` implementation. It contains no private session data and works offline.

GitHub Pages should be configured to deploy from the root of the `gh-pages` branch. `.nojekyll` prevents Jekyll processing.
